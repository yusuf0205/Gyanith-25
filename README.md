# Gyanith '25 Layout and Navigation Templates

Reusable responsive HTML and Tailwind CSS page templates created for **Gyanith '25**, the annual technical festival of the National Institute of Technology Puducherry (NITPY).

## Files

| File | Description |
| :--- | :--- |
| `Layout.html` | Full-page dark-theme shell combining the header, dynamic content container, and 3-column footer |
| `Navbar.html` | Standalone responsive navigation bar component |
| `footer.html` | Standalone festival footer with contact links (`gyanith@nitpy.ac.in`), quick navigation, and social links |
| `asset/logo.svg` | Official Gyanith vector logo |

## Usage

Open `Layout.html`, `Navbar.html`, or `footer.html` directly in a web browser (Tailwind CSS is loaded via CDN).
